LogScope 的日志查看器：logscope.py 是单文件程序，另附一份规格书加实现说明。程序已用 Textual 的无头测试跑过：解析、过滤、跟随、日志轮转、导出都通过，也测过 85 MB、60 万条的大文件。

主要功能

格式识别：自动识别 Python logging、logback、syslog、logfmt、JSON Lines。
堆栈合并：堆栈这类多行日志会并成一条，列表里显示 ⏎+N，底部详情面板看全文，JSON 会自动排版。
过滤：1–6 键切换级别，关键字支持 timeout redis -debug 这种“同时包含、排除某词”的写法，也可切到正则。命中的词会高亮。
实时跟踪：像 tail -f 一样自动追加，f 开关跟随，p 暂停；日志被轮转或清空时会自动重读。
其他：n/N 跳到下一个/上一个错误，s 导出当前过滤结果，支持鼠标点选。
